## Unreleased (2026-11-10, Revoked package digests, #2080)

- A catalog's `revoked_digests` are now persisted in `revoked-digests.json`, a sibling of `catalog-state.json` (which stays schema 1). An installed official package whose digest a later catalog revoked is refused with `package_revoked` for fresh launches, resume, relaunch, `plugin select`, enabling and profile pins; running sessions keep running and are flagged in `session list` and `plugin doctor`. Updated [runtime-packages](guides/runtime-packages.md), [runtime-catalog](concepts/runtime-catalog.md) and [runtime-package-archive](concepts/runtime-package-archive.md).
