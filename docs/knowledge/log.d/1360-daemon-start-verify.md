## Unreleased (2026-10-30, daemon start verifies the active version, #1360)

- `pohunek daemon start` in service mode verifies the active version directory (`layout::verify_installed`) before it runs that version's `pohunekd`, and refuses an untrusted one with `service_version_untrusted`, the code the service engine uses; a missing active version directory gets the same code. `--dev-subprocess` is unchanged.
- `pohunek service uninstall` verifies the active version directory before it starts a stopped daemon to list sessions, and treats a refusal as an unreachable daemon. The refusal of `daemon start` tells the operator that nothing must run from the directory and points to the [debug daemon runbook](runbooks/debug-daemon.md#active-version-directory-refused); the full recovery is tracked in #1763.
