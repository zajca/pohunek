## Unreleased (2026-11-10, Claude floor 2.1.309, #2084)

- The Claude package supports Claude Code from 2.1.309 (package version 2.0.0, range `[2.1.309, 3.0.0)`); an older release is refused at launch and resume with `agent_runtime_unsupported`. The manifest drops `authority_from`, the working and title screen rules and the `below_authority` mark, so the records are authoritative for every release; the dialog rules and the prompt box stay. A shell session answers the probe of a listed program (`[process]` matchers of the runtimes with `answer_probe`) running in the PTY foreground, so a hand-started Claude reports through records (additive worker `Initialize.probe_foreground_programs`). See [Claude package](guides/claude-package.md#program-status-osc-7501).
