## Unreleased (2026-11-12, delta dispatch reuse, #2203)

- A `workflow_dispatch` run of `ci.yml` with `tier=main` accepts `delta: true`: the `delta reuse` job finds the newest green pull request run of the same tree (within 24 hours) and the reusable jobs it names skip, reusing those legs instead of running them again. `scripts/ci-reuse` decides the skip list from `scripts/ci-reuse.json` (21 jobs, `mode != "full"` excludes the selection-dependent ones from a narrowed source, ambiguous sources run everything). A full dispatch (`delta: false`) stays the default and `scripts/release` keeps dispatching full runs. `scripts/ci-evidence` accepts the union of the evidence run and the recorded source run as evidence for the commit and names both runs in its report.
