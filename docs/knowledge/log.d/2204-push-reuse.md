## Unreleased (2026-11-13, push reuse, #2204)

- A `main` push of `ci.yml` while the workflow-level `CI_REUSE_PUSH` kill switch is `"true"` reuses the green legs of the previous runs of the same tree from this repository (pull request runs, prior main pushes, tier=main delta dispatches, within 24 hours, fork runs never). `scripts/ci-reuse` reads the consumer event: a delta dispatch only accepts a source on the same commit (`head_sha == GITHUB_SHA`), a `main` push may match by recorded tested tree; it decides per job the newest green leg among the candidates, writes per-job `run_id`s and a `source_runs` output, and writes the reuse record only on success. `scripts/ci-evidence` accepts dispatch evidence only from a same-commit source and push evidence from same-tree sources, verifies each reused job against its own source run (age per leg, `success` conclusion, required steps by display name) and names all of them. `test-duplicates` downloads the reused and own JUnit reports in age order from every source run. `cargo-audit` is never reused, the advisory database changes independently of the tree; nightly and schedule runs never reuse; the delta dispatch is unchanged.
