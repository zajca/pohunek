The assistant knowledge bundle has an onboarding guide (`guide/onboarding`, intents `setup` and `project`) for an assistant session marked with `onboard.mode`: host checks with their fix owner, project proposals from `pohunek project candidates`, session groups, profiles created only through `pohunek plugin profile create`, the guided and automatic mode rules with a non-grantable floor, and the Claude allow and deny rules and Codex arguments of the `pohunek-onboard` launch profile. It reaches users with the next assistant package release. ([#2344](https://github.com/zajca/pohunek/issues/2344))
