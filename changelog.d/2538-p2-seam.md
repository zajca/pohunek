The worker's terminal snapshot can now be built on libghostty-vt instead of the vt100 parser: the new `libghostty` cargo feature of `pohunek-terminal` links the pinned static library through the new `pohunek-terminal-ghostty-sys` crate (issue #2538), and `TerminalTracker` runs either screen model via `with_model`. The feature default is off (`default = []`; the 0.46 default flip turns it on), so no shipped binary changes and no behavior changes: vt100 stays the default model and the fallback build is `--no-default-features`, with no Zig and no C library. ([#2538](https://github.com/zajca/pohunek/issues/2538))
