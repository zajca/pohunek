`packaging/install-daemon.sh` now works on NixOS: the archive check finds `id` in `/usr/bin`, `/bin` or the NixOS system profile instead of requiring `/usr/bin/id`. On macOS, an upgrade refused as `service_upgrade_sessions_at_risk` now also names a recorded search-path entry that a new install would not record (for example a Nix profile path of an older generation) and points to `pohunek service uninstall` and `pohunek service install` instead of `--accept-runtime-loss`.
