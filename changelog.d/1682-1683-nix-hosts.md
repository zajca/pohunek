`packaging/install-daemon.sh` now works on NixOS: the archive check finds `id` in `/usr/bin`, `/bin` or the NixOS system profile instead of requiring `/usr/bin/id`. On macOS, an upgrade refused as `service_upgrade_sessions_at_risk` now also names the search path recorded in `service.toml` (for example a Nix profile path of an older generation) and points to `pohunek service refresh-path --dry-run` and `pohunek service refresh-path` (run with the `pohunek` of the release being installed, then rerun the upgrade) instead of `--accept-runtime-loss`.
