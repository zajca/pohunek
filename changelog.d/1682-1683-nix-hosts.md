`packaging/install-daemon.sh` now works on NixOS: the archive check finds `id` in `/usr/bin`, `/bin` or the NixOS system profile instead of requiring `/usr/bin/id`. On macOS, when a fresh login-shell discovery succeeds, an upgrade refused as `service_upgrade_sessions_at_risk` now also names the recorded search-path entries that a new install would not record (for example a Nix profile path of an older generation) and points to re-recording the path (`pohunek service uninstall`, reinstall the installed version, rerun the upgrade) instead of `--accept-runtime-loss`.
