Host agent profiles can declare launch options: closed `[options.<id>]` enumerations (a model, an effort level, a permission mode) with a label, a default and choices that add launch args, env entries and an optional `min_runtime` floor. `pohunek session new --opt OPTION=CHOICE` (and `agent_options` on `session.new`, behind the new `session_new_agent_options_supported` capability) selects choices; every option not named takes its default, and the session records and reports the resolved choices as `agent_options`. A floored choice is available only when the runtime's probed version meets it, and a runtime without a version fails closed. Resume relaunches with the recorded choices: label, default and unselected-choice edits need no decision, an edited selected choice is `agent_profile_changed`, and a removed one is `agent_option_choice_missing`. `host.inspect` reports each profile's options with their availability, `pohunek plugin profile show <name>` prints them, and the store moves to schema 20. ([#2147](https://github.com/zajca/pohunek/issues/2147))
