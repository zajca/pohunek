Claude Code below 2.1.309 is no longer supported. The Claude runtime package is version 2.0.0 and accepts `[2.1.309, 3.0.0)`: a launch or resume with an older `claude` is refused with `agent_runtime_unsupported`, and `pohunek service upgrade` reports a stopped session whose installed Claude is older as unable to recover until a supported release is installed or `--accept-runtime-loss` is given. Every supported Claude reports OSC 7501 program-status records, so the Claude detection manifest no longer declares `authority_from` (its records are authoritative for every release) and drops the title, status-line and completed-turn rules that read a running turn without records (a Claude launched with its records off now reads idle during a turn). A shell session's worker now answers the OSC 7501 probe of a Claude (or Pi) that a person starts by hand in the PTY foreground, so its records drive the session (additive `Initialize.probe_foreground_programs`; a worker started by an older daemon keeps answering nothing below a shell); the prompt box and every dialog rule stay.
